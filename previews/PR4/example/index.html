End-to-end example

A realistic Case-1 water workflow: build the biogeochemistry, compute inherent optical properties over the visible, inspect the inelastic source kernels, and differentiate the absorption coefficient with respect to wavelength.

All code blocks below are executed at documentation-build time by Documenter's @example machinery, so the numerical outputs in the rendered page are the actual package outputs.

Biogeochemistry

Open-ocean oligotrophic water at Chl = 0.5 mg/m³, surface temperature T = 20 °C, practical salinity S = 35.

using OceanOptics

water = PureWater{Float64}(
    absorption_model = IOCCG2018(),
    scattering_model = ZhangHu2009(),
    temperature      = 20.0,
    salinity         = 35.0,
)
cdom  = CDOM{Float64}(a_ref = 0.03, λ_ref = 440.0, slope = 0.014)
phyto = Phytoplankton{Float64, Bricaud1998}(Chl = 0.5)

Each constituent exposes the same absorption / scattering / backscattering traits. Spot-checks at the chlorophyll blue peak:

λ = 440.0
a_water = absorption(water, λ)
b_water = scattering(water, λ)
a_cdom  = absorption(cdom, λ)
a_phyto = absorption(phyto, λ)
b_phyto = scattering(phyto, λ)
(a_water, b_water, a_cdom, a_phyto, b_phyto)
(0.00635, 0.004379595171013634, 0.03, 0.03348492236725546, 0.24400159789536252)

Building a layer and computing the optical bundle

Stack the three constituents in a 5-m surface layer and compute its optical properties at 10-nm resolution across the visible. The result holds one absorption component per absorber and one scattering component per scattering constituent (here water and phytoplankton; CDOM only absorbs):

layer = OceanLayer(0.0, 5.0,
                   AbstractOceanConstituent{Float64}[water, cdom, phyto])
λ_grid = collect(400.0:10.0:700.0)
opt    = layer_optics(layer, λ_grid; ℓ_max = 32)
[(c.label, c.part) for c in opt.absorbers], [(c.label, c.polarization) for c in opt.scatterers]
([("PureWater", :total), ("CDOM", :total), ("Phytoplankton", :total)], [("PureWater", :scalar), ("Phytoplankton", :scalar)])

Mixed quantities are derived from the components:

using Printf
τ, ϖ, B = optical_depth(opt), single_scattering_albedo(opt), backscatter_fraction(opt)
println(" λ [nm]   τ         ϖ         B")
for i in 1:5:length(λ_grid)
    @printf("%6.0f  %.5f   %.4f   %.4f\n", λ_grid[i], τ[i], ϖ[i], B[i])
end

Each component carries its own expansion; the mixture at a wavelength is their scattering-weighted average, with β₀ = 1:

mixed = greek_expansion(opt, 1)
(n_moments(mixed), mixed.β[1], mixed.β[2] / 3)   # terms, β₀, asymmetry parameter at 400 nm
(33, 1.0, 0.934828876264724)

Chlorophyll absorption and fluorescence

To follow the light absorbed by chlorophyll, give the phytoplankton a pigment partition. ProspectPigments splits its absorption into chlorophyll and carotenoids with the leaf spectra of PROSPECT-D (the land analogy); Bidigare1990Pigments uses ocean pigment groups. The total absorption is unchanged:

pig = Phytoplankton(Chl = 0.5, pigments = ProspectPigments(carotenoid_ratio = 0.3))
a = absorption_by_part(pig, 490.0)
(absorption_parts(pig), a, sum(a) ≈ absorption(pig, 490.0))
((:chlorophyll, :carotenoids, :unassigned), (0.00999323238471986, 0.01219464625056511, 0.0), true)

Fluorescence is excited by chlorophyll absorption and by the share η of carotenoid absorption passed to chlorophyll (0: chlorophyll only; 1: lossless antenna). The default emission is the chloroplast-level spectrum of the leaf model Fluspect; the quantum yield is always given:

chl_only = chlorophyll_fluorescence(pig; quantum_yield = 0.02, carotenoid_transfer = 0.0)
antenna  = chlorophyll_fluorescence(pig; quantum_yield = 0.02, carotenoid_transfer = 0.5)
excitation_absorption(chl_only, 490.0), excitation_absorption(antenna, 490.0)
(0.0001998646476943972, 0.0003218111102000483)

The emission density (photons per nm) has its maxima at 685 and 739 nm:

using Printf
println(" λ [nm]    f(λ) [1/nm]")
for λ in (660.0, 685.0, 700.0, 720.0, 739.0, 760.0, 800.0)
    @printf("%6.1f    %.5f\n", λ, emission(antenna, 440.0, λ))
end

Fluorescence converts photons (conversion_units), so the energy kernel radiance_source_kernel is the photon kernel times the photon-energy ratio λ'/λ:

radiance_source_kernel(antenna, 440.0, 685.0) / inelastic_coefficient(antenna, 440.0, 685.0)
0.6423357664233577

In a layer, the process is linked to the absorption components that excite it, and the light each component absorbs follows from the solver's layer-mean scalar irradiance. Here a uniform 1 W m⁻² nm⁻¹ stands in for the solver's field:

lay = layer_optics(OceanLayer(0.0, 5.0, AbstractOceanConstituent{Float64}[water, pig];
                              inelastic = AbstractOceanInelasticProcess{Float64}[antenna]),
                   collect(400.0:5.0:750.0))
E₀  = ones(n_wavelengths(lay))
par = absorbed_par(lay, E₀)                  # µmol photons m⁻² s⁻¹ per absorption component
[(c.label, c.part, round(p; sigdigits = 4)) for (c, p) in zip(lay.absorbers, par)]
4-element Vector{Tuple{String, Symbol, Float64}}:
 ("PureWater", :total, 1206.0)
 ("Phytoplankton", :chlorophyll, 56.36)
 ("Phytoplankton", :carotenoids, 32.06)
 ("Phytoplankton", :unassigned, 0.0)
λ_em = collect(640.0:1.0:850.0)
P    = inelastic_emission(lay, 1, E₀, λ_em)  # W m⁻² nm⁻¹ emitted by the layer
λ_em[argmax(P)], maximum(P)

Water Raman at 440-nm excitation peaks around 517 nm (the 3400 cm⁻¹ Stokes shift of the O–H stretch):

ram = WaterRaman{Float64}()
(raman_peak_wavelength(ram, 440.0),
 excitation_absorption(ram, 440.0),
 emission(ram, 440.0, 517.0))
(517.4035747883349, 0.0004771809137890739, 0.1728498373727862)

The Raman coefficient is an energy conversion coefficient (Mobley et al. 1993): the energy kernel is b_R f_R without a photon-energy ratio, and the angular distribution is the Rayleigh-type phase function for the depolarization ratio of the band:

(conversion_units(ram),
 radiance_source_kernel(ram, 440.0, 517.0) / (excitation_absorption(ram, 440.0) * emission(ram, 440.0, 517.0)),
 phase_function_moments(raman_phase(ram), 2))
(EnergyConversion(), 1.0, [1.0, 0.0, 0.30970149253731344])

Forward-mode automatic differentiation

The scalar functions absorption, scattering and backscattering accept a ForwardDiff.Dual wavelength; phase_function_value of the Fournier-Forand and Henyey-Greenstein phase functions accepts a dual μ; and absorbed_power, absorbed_photons and absorbed_par accept a dual irradiance. Spectral sensitivity of the total absorption coefficient at 440 nm:

using ForwardDiff
∂a_∂λ = ForwardDiff.derivative(
    λ -> absorption(water, λ) + absorption(cdom, λ) + absorption(phyto, λ),
    440.0,
)
-0.0003208362976481302

Model parameters carry dual numbers too. The element type of a constituent is any Real; a constructor without an explicit type takes it from its parameters. The derivative of the CDOM absorption with respect to its spectral slope, against the closed form ∂a/∂S = −(λ − λ_ref) a:

(ForwardDiff.derivative(S -> absorption(CDOM(slope = S), 500.0), 0.014),
 -(500.0 - 440.0) * absorption(CDOM(slope = 0.014), 500.0))
(-0.7770789421723435, -0.7770789421723435)

layer_optics and column_optics accept layers of dual element type and return optical depths that carry the derivative. Here the derivative of the absorption optical depth of a 5 m layer with respect to chlorophyll; every constituent of the layer is built at the element type of Chl:

λ_ad = [443.0, 551.0, 670.0]
function absorption_depth(Chl)
    FT    = typeof(Chl)
    layer = OceanLayer(0.0, 5.0, AbstractOceanConstituent{FT}[
                PureWater{FT}(), CDOM{FT}(), Phytoplankton{FT}(Chl = Chl)])
    return absorption_optical_depth(layer_optics(layer, λ_ad; ℓ_max = 16))
end
∂τ_∂Chl = ForwardDiff.derivative(absorption_depth, 0.5)
3-element Vector{Float64}:
 0.20676164148824067
 0.05444234801792535
 0.09231979824470454

A central difference gives the same numbers, and the logarithmic derivative of the phytoplankton part is the Bricaud exponent E(λ) < 1: the absorption is not linear in chlorophyll.

h = 1e-6
(∂τ_∂Chl, (absorption_depth(0.5 + h) .- absorption_depth(0.5 - h)) ./ 2h)
([0.20676164148824067, 0.05444234801792535, 0.09231979824470454], [0.206761641502462, 0.05444234801865733, 0.0923197982505286])

The backscatter fraction of a Fournier-Forand phase function is carried through the Legendre expansion as well (the inversion to (n, μ_j) is linearized at its root, and the quadrature runs in dual numbers):

ForwardDiff.derivative(
    B -> phase_function_moments(FournierForandPhase(backscatter_fraction = B), 4), 0.018)

   0.0

Not differentiable with respect to parameters: the inelastic processes (WaterRaman, fluorescence) and their emission spectra, which are floating point only (their kernels accept dual wavelengths), and the measured phase tables (PetzoldPhase, TabulatedMuellerPhase). A constituent of fixed floating-point type cannot store a dual parameter: CDOM{Float64}(slope = S) with a dual S is a MethodError. The consumer interface lists every differentiable parameter.

test/test_ad.jl holds the tested cases: each parameter derivative against a central difference or a closed form, for the scalar functions and through layer_optics and column_optics; wavelength, scattering-angle and irradiance derivatives; and the rejected cases.
