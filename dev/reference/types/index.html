Foundational type spine — the abstract hierarchy, the volumetric IOP bundle, layers and columns, and the solver-facing optics. Phase-function and inelastic-process types are documented on Phase functions and Inelastic processes; material models on Materials.

Module

OceanOptics — Module
OceanOptics

Inherent optical properties (IOPs) and phase-matrix expansions of natural waters, for plane-parallel radiative-transfer solvers — primarily the coupled atmosphere–ocean solver in vSmartMOM.jl, without depending on it.

  • Constituents: PureWater, CDOM, Phytoplankton, NonAlgalParticles, and exact published values (TabulatedAbsorber, TabulatedScatterer).
  • Phase functions and matrices: RayleighWaterPhase, FournierForandPhase, HenyeyGreensteinPhase, PetzoldPhase, TabulatedGreekPhase, TabulatedMuellerPhase, WavelengthDependentPhase, all expanded as GreekCoefficients in vSmartMOM's convention.
  • layer_optics → OceanLayerOptics: absorption optical depth plus one scattering component per constituent; column_optics → OceanColumnOptics with the interface refractive index and the bottom.
  • Inelastic process kernels (fluorescence, water Raman) for the solver.

Units, conventions and validation rules are on the Consumer API docs page.

OceanOptics.AbstractAbsorbingScatterer — Type
abstract type AbstractAbsorbingScatterer{FT} <: AbstractAbsorber{FT}

Constituents that both absorb and scatter (phytoplankton, non-algal particles, pure water). Must implement both absorption and scattering, and provide a scattering_phase.

Subtypes AbstractAbsorber: any AbstractAbsorbingScatterer is dispatchable wherever an AbstractAbsorber is required. DESIGN §4.1 called for joint inheritance from both AbstractAbsorber and AbstractScatterer, which Julia's single-inheritance model cannot express; we pick AbstractAbsorber as the parent because the bulk of downstream code (inelastic source operators in §7, constituent-mixing helpers) dispatches through absorption-centric slots. Scatterer-centric behavior is still reachable via specific methods on each concrete absorbing-scatterer type.

Volumetric IOPs

OceanOptics.IOP — Type
struct IOP{FT<:AbstractFloat, A<:Union{AbstractArray{FT<:AbstractFloat}, FT<:AbstractFloat}}

Bundle of inherent optical properties at one wavelength (or one wavelength grid). This is the neutral currency of the package: every constituent produces an IOP, constituents mix via +, and layers reduce to a single IOP before being expanded into an OceanLayerOptics.

An IOP is wavelength-local: the scalar-field version describes one λ; the vector-field version describes a λ grid. Same struct, parametric fields.

Fields

  • a::Union{AbstractArray{FT}, FT} where FT<:AbstractFloat: Absorption coefficient a(λ) [1/m]

  • b::Union{AbstractArray{FT}, FT} where FT<:AbstractFloat: Scattering coefficient b(λ) [1/m]

  • bb::Union{AbstractArray{FT}, FT} where FT<:AbstractFloat: Backscattering coefficient b_b(λ) [1/m]. Optional: zero for pure absorbers.

Example

iop1 = IOP(0.1, 0.05, 0.018)       # pure water at 550 nm
iop2 = IOP(0.03, 0.30, 0.012)      # phytoplankton contribution
total = iop1 + iop2                # correctly energy-weights backscatter

Solver output

OceanOptics.layer_optics — Function
layer_optics(layer, λ; ℓ_max = 64, polarized = false,
             scalar_phase_approximation = nothing, FT = Float64) -> OceanLayerOptics

Optical properties of one OceanLayer at wavelengths λ [nm] (strictly monotone, increasing or decreasing).

Keywords

  • ℓ_max — highest expansion order. The expansions are exact through ℓ_max (to the quadrature tolerance) and not truncated further: δ-M or similar truncation is the solver's choice and needs ℓ_max at least as large as its fitting order.
  • polarized — also compute phase-matrix coefficients α, γ, δ, ϵ, ζ.
  • scalar_phase_approximation — with polarized = true, how to treat scatterers whose phase function is scalar-only (Fournier-Forand, Henyey-Greenstein, Petzold): nothing throws; :depolarizing uses the completely depolarizing approximation, labelled :depolarizing on the component. Applies to every such scatterer, even one with zero scattering. Ignored when polarized = false.
  • FT — floating-point type of the result.

Result

An OceanLayerOptics with the absorption optical depth and one ScatteringComponent per scattering constituent, in constituent order. Mixed quantities follow from optical_depth, single_scattering_albedo and greek_expansion(o, iλ).

If a constituent declares is_total_absorption (a TabulatedAbsorber with total = true), it must be the only one, and every other constituent must have zero absorption at every wavelength.

Inelastic processes in layer.fluorophores are not included; they are source terms for the solver (see the Consumer API docs page).

Example

water = PureWater{Float64}()
phyto = Phytoplankton{Float64, Bricaud1998}(Chl = 0.5)
layer = OceanLayer(0.0, 5.0, AbstractOceanConstituent{Float64}[water, phyto])
opt   = layer_optics(layer, collect(400.0:5.0:700.0); ℓ_max = 64)
optical_depth(opt), single_scattering_albedo(opt)
opt.components[2].label               # "Phytoplankton"

OceanOptics.column_optics — Function
column_optics(column, λ; refractive_index, bottom, ℓ_max = 64, polarized = false,
              scalar_phase_approximation = nothing, FT = Float64) -> OceanColumnOptics

Optical description of an OceanColumn for a coupled atmosphere–ocean solver: layer_optics for every layer on the same grid and settings, the interface refractive index, and the bottom.

Components with the same phase function and polarization treatment share one phase_id and the same expansion objects across layers.

refractive_index (an AbstractRefractiveIndexModel, e.g. FixedRefractiveIndex(1.34) or QuanFry1995(; temperature, salinity)) and bottom (BlackBottom() or LambertianBottom(albedo)) are required: neither has a defensible default.

Example

water  = PureWater{Float64}()
column = uniform_column(AbstractOceanConstituent{Float64}[water]; n_layers = 4, depth = 20.0)
col    = column_optics(column, [450.0, 550.0]; refractive_index = FixedRefractiveIndex(1.34),
                       bottom = BlackBottom(), polarized = true)

OceanOptics.OceanLayerOptics — Type
struct OceanLayerOptics{FT}

Optical properties of one homogeneous ocean layer on a wavelength grid, produced by layer_optics.

Fields

  • λ::Vector: Wavelengths [nm], strictly monotone

  • depth_top::Any: Depth of the layer top below the surface [m]

  • depth_bottom::Any: Depth of the layer bottom below the surface [m]

  • τ_abs::Vector: Absorption optical depth a·Δz per wavelength (all absorbers)

  • components::Array{ScatteringComponent{FT}, 1} where FT: Scattering components, one per scattering constituent

  • n_moments::Int64: Number of expansion terms, ℓ_max + 1

  • polarized::Bool: Whether every component carries phase-matrix coefficients

Derived quantities

optical_depth, scattering_optical_depth, single_scattering_albedo, backscatter_fraction and the mixed expansion greek_expansion(o, iλ) — the scattering-weighted mixture of the components.

Validation

λ finite, positive and strictly monotone (increasing or decreasing); 0 ≤ depth_top < depth_bottom; optical depths finite and non-negative; every component on the same wavelength grid, with n_moments terms and the layer's polarization. Arrays are checked at construction; mutating them afterwards is not re-checked.

source
OceanOptics.ScatteringComponent — Type
struct ScatteringComponent{FT}

Scattering by one constituent of a layer.

Fields

  • label::String: Constituent the component came from (type name, or the source of tabulated data)

  • phase_id::UInt64: Identity of the phase function and polarization treatment (equal ⇒ identical expansions)

  • τ::Vector: Scattering optical depth b·Δz per wavelength

  • greek::Array{GreekCoefficients{FT}, 1} where FT: Distinct phase-matrix expansions

  • backscatter_fraction::Vector: Backscatter fraction of the phase function (not of its truncated expansion), per entry of greek

  • phase_index::Vector{Int64}: Entry of greek used at each wavelength; empty when there is a single entry

  • polarization::Symbol: :scalar, :full or :depolarizing

greek and backscatter_fraction hold the component's distinct expansions: one when the phase function does not depend on wavelength; otherwise phase_index[iλ] names the entry used at each wavelength of the layer. See greek_expansion(c, iλ) and is_wavelength_dependent(c).

phase_id identifies the phase function and polarization treatment: components with equal phase_id (in any layer of a column) have identical expansions — column_optics shares the same objects — so a solver can build their phase operators once.

polarization records how the phase-matrix coefficients were obtained: :scalar (phase function only, β), :full (the constituent's phase matrix), or :depolarizing (its phase function with the completely depolarizing approximation, selected explicitly).

OceanOptics.OceanColumnOptics — Type
struct OceanColumnOptics{FT, B<:AbstractOceanBottom}

Optical description of a whole water column, produced by column_optics: contiguous layers from the surface down on one wavelength grid, the refractive index of the water at the surface relative to air, and the bottom.

Fields

  • layers::Array{OceanLayerOptics{FT}, 1} where FT: Layers, surface first

  • refractive_index::Vector: Refractive index of the surface water relative to air, per wavelength

  • bottom::AbstractOceanBottom: Lower boundary

Layers share λ, n_moments and polarization; the first starts at the surface and each starts where the previous one ends. refractive_index is real and given per wavelength.
