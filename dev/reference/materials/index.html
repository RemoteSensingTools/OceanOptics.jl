Pure (sea)water

OceanOptics.PureWater — Type
struct PureWater{FT, A<:AbstractPureWaterAbsorptionModel, S<:AbstractPureWaterScatteringModel} <: AbstractAbsorbingScatterer{FT}

Pure (sea)water as an optical constituent.

Fields

  • absorption_model::AbstractPureWaterAbsorptionModel: Absorption-model choice (tag)

  • scattering_model::AbstractPureWaterScatteringModel: Scattering-model choice (tag)

  • temperature::Any: Temperature [°C]

  • salinity::Any: Salinity [PSU] (Practical Salinity Unit)

  • depolarization::Any: Depolarization ratio for the Rayleigh-type scattering phase function

Examples

# Default: IOCCG2018 absorption, Zhang-Hu scattering, S = 35 PSU, T = 20 °C
water = PureWater{Float64}()

# Legacy Pope-Fry + Morel combination
water = PureWater{Float64}(
    absorption_model = PopeFry1997(),
    scattering_model = Morel1974(),
)

# Cold, freshwater Arctic case
water = PureWater{Float64}(temperature = 2.0, salinity = 2.0)

OceanOptics.IOCCG2018 — Type

IOCCG Protocol Series (2018) recommended pure-water absorption: Morel et al. (2007) for 340–415 nm, Pope & Fry (1997) for 420–725 nm and Kou et al. (1993) for 730–750 nm, at 5 nm resolution over 350–750 nm as used for the HydroLight database of Loisel et al. (2023); continued with Kou et al. (1993) up to 2500 nm. The composite's 730–750 nm values differ from the bundled Kou table by up to 0.8 % (0.06 % step at the 750 nm junction). The default model.

Pope & Fry (1997), 380–727.5 nm, 2.5 nm resolution, measured at 22 °C.

source
OceanOptics.Kou1993 — Type

Kou, Labrie & Chylek (1993), 667–2500 nm, ~1 nm resolution, measured at 22 °C.

OceanOptics.SmithBaker1981 — Type

Smith & Baker (1981), 200–800 nm, 10 nm resolution: upper bounds for the clearest natural waters. Below ~420 nm it is several times higher than modern pure-water measurements. No temperature correction is applied.

source
OceanOptics.Morel1974 — Type

Morel (1974). Salinity-independent: b_w(λ) = 0.00193 (550/λ)^4.32.

source
OceanOptics.ZhangHu2009 — Type

Zhang, Hu & He (2009). Includes salinity and temperature dependence. 200–1100 nm.

OceanOptics.QuanFry1995 — Type
struct QuanFry1995{FT<:AbstractFloat} <: AbstractRefractiveIndexModel

Quan & Fry (1995) empirical refractive index of seawater relative to air,

n = n₀ + (n₁ + n₂T + n₃T²) S + n₄T² + (n₅ + n₆S + n₇T)/λ + n₈/λ² + n₉/λ³

with λ in nm, T in °C and S in PSU, fitted to Austin & Halikas (1976) data over 400–700 nm, 0–30 °C and 0–35 PSU.

Fields

  • temperature::AbstractFloat: Temperature [°C]

  • salinity::AbstractFloat: Salinity [PSU]

  • extrapolate::Bool: Allow use outside 400–700 nm, 0–30 °C, 0–35 PSU

Queries outside the fitted domain throw unless extrapolate = true.

CDOM

OceanOptics.CDOM — Type
struct CDOM{FT, M<:AbstractCDOMModel} <: AbstractAbsorber{FT}

Coloured Dissolved Organic Matter (CDOM) as a pure absorber.

Fields

  • model::AbstractCDOMModel: Parameterization-model tag (e.g. BricaudMorelPrieur1981())

  • a_ref::Any: Reference absorption a_g(λ_ref) [1/m]

  • λ_ref::Any: Reference wavelength [nm] at which a_ref is anchored

  • slope::Any: Spectral slope S [1/nm]

Examples

# Open-ocean default: a_g(440 nm) = 0.03 m⁻¹, slope 0.014 nm⁻¹
cdom = CDOM{Float64}()

# Coastal / humic-rich case
cdom_coastal = CDOM{Float64}(a_ref = 0.5, λ_ref = 440.0, slope = 0.017)

# Evaluate
absorption(cdom, 440.0)   # ≈ 0.03
absorption(cdom, 500.0)   # exponentially smaller

OceanOptics.BricaudMorelPrieur1981 — Type
struct BricaudMorelPrieur1981 <: AbstractCDOMModel

Bricaud, Morel & Prieur (1981) exponential-decay CDOM absorption, a_g(λ) = a_g(λ_ref) · exp(-slope · (λ - λ_ref)). Currently the only parameterization shipped; future additions (e.g. separate slopes for the UV and visible hinge regions) can subtype AbstractCDOMModel without altering CDOM itself.

Phytoplankton

OceanOptics.Phytoplankton — Type
struct Phytoplankton{FT, M<:AbstractPhytoplanktonModel, P<:AbstractOceanPhaseFunction{FT}} <: AbstractAbsorbingScatterer{FT}

Phytoplankton (living algal cells) as an absorbing scatterer.

Chl is the near-surface chlorophyll-a concentration [mg/m³]. The model tag M selects the absorption parameterization; scattering currently uses Morel & Maritorena (2001) irrespective of M, and the phase function defaults to FournierForandPhase with backscatter fraction 0.01 (typical open-ocean living phytoplankton).

Fields

  • model::AbstractPhytoplanktonModel: Parameterization-model tag (e.g. Bricaud1998())

  • Chl::Any: Chlorophyll-a concentration [mg/m³]

  • phase::AbstractOceanPhaseFunction{FT} where FT: Particulate-scattering phase function

Examples

# Open-ocean Case-1 water at Chl = 0.5 mg/m³
phyto = Phytoplankton{Float64, Bricaud1998}(Chl = 0.5)

# Custom backscatter fraction (coastal, larger cells)
phyto = Phytoplankton{Float64, Bricaud1998}(Chl = 2.0, B = 0.015)

Non-algal particles

OceanOptics.NonAlgalParticles — Type
struct NonAlgalParticles{FT, M<:AbstractNAPModel, P<:AbstractOceanPhaseFunction{FT}} <: AbstractAbsorbingScatterer{FT}

Non-algal particulate matter (detritus + minerals) as an absorbing scatterer.

Fields

  • model::AbstractNAPModel: Parameterization-model tag (e.g. BabinBricaud2003() or FellMineral())

  • a_ref::Any: Reference absorption a_nap(λ_ref) [1/m] (BabinBricaud2003)

  • b_ref::Any: Reference scattering b_nap(λ_ref) [1/m] (BabinBricaud2003)

  • λ_ref::Any: Reference wavelength [nm]

  • slope::Any: Exponential absorption slope [1/nm] (BabinBricaud2003)

  • c_ref::Any: Beam attenuation at 440 nm [1/m] (FellMineral)

  • ω_nap::Any: Single-scattering albedo at 440 nm (FellMineral)

  • phase::AbstractOceanPhaseFunction{FT} where FT: Particulate-scattering phase function

Examples

# Babin et al. (2003) default: a_nap(443) = 0.05 m⁻¹, S = 0.011 1/nm
nap = NonAlgalParticles{Float64}()

# Mineral-dominated case per Fell (1997)
nap = NonAlgalParticles{Float64, FellMineral}(
    c_ref  = 0.40,   # beam attenuation at 440 nm
    ω_nap  = 0.96,   # single-scattering albedo
)

Tabulated constituents

Exact published coefficients, without an empirical model; see Consumer API for the absorption-scope rule.

OceanOptics.TabulatedAbsorber — Type
struct TabulatedAbsorber{FT} <: AbstractAbsorber{FT}

Absorber defined by tabulated absorption coefficients at exact wavelengths.

Fields

  • λ::Vector: Wavelengths [nm], strictly increasing

  • a::Vector: Absorption coefficient [1/m] at each λ

  • total::Bool: Whether a is the bulk absorption of the whole layer

  • source::String: Provenance: citation, table, and any transformation applied

Construction

TabulatedAbsorber(λ, a; total = false, source = "")

λ [nm] must be strictly increasing; a [1/m] finite and non-negative. Set total = true when a is the bulk absorption of the whole layer (all absorbers, including water): layer_optics then requires every other constituent in the layer to have zero absorption.

Example

# Chowdhary et al. (2020) Table 2, AOS-II/III: a_blk = a_w
a_blk = TabulatedAbsorber([350.0, 450.0, 550.0, 650.0],
                          [0.0204, 0.0092, 0.0565, 0.3400];
                          total = true, source = "Chowdhary et al. 2020, Table 2")
absorption(a_blk, 450.0)   # 0.0092
absorption(a_blk, 500.0)   # ArgumentError: not a tabulated wavelength
source
OceanOptics.TabulatedScatterer — Type
struct TabulatedScatterer{FT, P<:AbstractOceanPhaseFunction{FT}} <: AbstractScatterer{FT}

Non-absorbing scatterer defined by tabulated scattering coefficients at exact wavelengths and a phase function (or phase matrix).

Fields

  • λ::Vector: Wavelengths [nm], strictly increasing

  • b::Vector: Scattering coefficient [1/m] at each λ

  • phase::AbstractOceanPhaseFunction{FT} where FT: Phase function or phase matrix

  • source::String: Provenance: citation, table, and any transformation applied

Construction

TabulatedScatterer(λ, b, phase; source = "")

λ [nm] must be strictly increasing; b [1/m] finite and non-negative. phase is any AbstractOceanPhaseFunction; a wavelength-dependent TabulatedGreekPhase must tabulate every wavelength in λ. The backscattering coefficient is derived from the phase function, b_b = b · B, so the two can never disagree; for a TabulatedGreekPhase, B is that of the tabulated (possibly truncated) expansion. Model an absorbing component as a TabulatedAbsorber plus a TabulatedScatterer.

Example

# Chowdhary et al. (2020) AOS-II/III: pure-seawater scattering, δ_w = 0
water_scat = TabulatedScatterer([350.0, 450.0, 550.0, 650.0],
                                [0.0134, 0.0045, 0.0019, 0.0010],
                                RayleighWaterPhase(depolarization = 0.0);
                                source = "Chowdhary et al. 2020, Table 2")
