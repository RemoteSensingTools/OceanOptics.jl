OceanOptics.RayleighWaterPhase — Type
struct RayleighWaterPhase{FT} <: AbstractOceanPhaseFunction{FT}

Rayleigh-type phase function for pure water, with depolarization.

Fields

  • depolarization::Any: Depolarization ratio ρ = I⟂ / I∥ at 90°

Default depolarization = 0.039 follows Farinato & Rowell (1976) and is consistent with the Zhang, Hu & He (2009) pure-seawater model. The Morel (1974) older value ρ = 0.09 can be selected explicitly:

RayleighWaterPhase{Float64}(depolarization = 0.09)

OceanOptics.FournierForandPhase — Type
struct FournierForandPhase{FT} <: AbstractOceanPhaseFunction{FT}

Fournier-Forand phase function for ocean particles.

Fields

  • n::Any: Real refractive index of the particles relative to water

  • μ_j::Any: Junge slope of the particle size distribution, 3 < μ_j < 5

Construction

FournierForandPhase{Float64}(n = 1.10, μ_j = 3.5835)       # B ≈ 0.0183
FournierForandPhase{Float64}(backscatter_fraction = 0.01)  # Mobley et al. (2002) family

With backscatter_fraction = B, (n, μ_j) are found on the family n = 1.01 + 0.1542 (μ_j − 3) of Mobley, Sundman & Boss (2002); B must lie in the range that family spans for 3 < μ_j < 5. The field is called μ_j (Junge slope) because μ denotes cos θ throughout this package.

struct PetzoldPhase{FT} <: AbstractOceanPhaseFunction{FT}

Petzold (1972) "San Diego Harbor" particulate phase function (Mobley 1994, Table 3.10), a scalar phase function.

Fields

  • θ::Vector: Tabulated scattering angles [rad], ascending, from 0.1° to 180°

  • p::Vector: Normalized phase function at those angles

  • b::Any: Scattering coefficient implied by the tabulated VSF and its extrapolation, 4π·(1/2)∫β dμ [1/m]

Power-law interpolation between the 55 tabulated angles; power-law extrapolation below 0.1° using the first two nodes; normalized as (1/2)∫p dμ = 1 for this interpolant.

OceanOptics.TabulatedGreekPhase — Type
struct TabulatedGreekPhase{FT} <: AbstractOceanPhaseFunction{FT}

Phase function or phase matrix given by its Greek expansion.

Fields

  • greek::GreekCoefficients{FT} where FT: The expansion

  • source::String: Provenance: citation, table, and any transformation applied

Construction

TabulatedGreekPhase(g::GreekCoefficients; source = "")
TabulatedGreekPhase(β; α, γ, δ, ϵ, ζ, source = "", normalize = false)

The keyword form builds the GreekCoefficients (pass none or all of α, γ, δ, ϵ, ζ). normalize = true divides all six coefficients by β₀, an explicit choice for published tables rounded to a few digits. The expansion must also give a backscatter fraction in [0, 1], which a strongly peaked table truncated far before convergence can fail.

Requests for ℓ_max below the table length truncate it; requests above pad with zeros, which is exact for the tabulated expansion.

Example

# Rayleigh scattering without depolarization, as a phase matrix
pf = TabulatedGreekPhase([1.0, 0.0, 0.5]; α = [0.0, 0.0, 3.0],
                         γ = [0.0, 0.0, sqrt(1.5)], δ = [0.0, 1.5, 0.0],
                         ϵ = zeros(3), ζ = zeros(3), source = "Hansen & Travis (1974)")
greek_expansion(pf, 8; polarized = true).γ[3]    # √(3/2)

OceanOptics.TabulatedMuellerPhase — Type
struct TabulatedMuellerPhase{FT} <: AbstractOceanPhaseFunction{FT}

Phase matrix given by its angular scattering matrix F(Θ).

Fields

  • θ::Vector: Scattering angles [rad], strictly increasing from 0 to π

  • F11::Vector: F11 (phase function), normalized so that (1/2)∫F11 dμ = 1

  • F12::Vector: F12 = F21

  • F22::Vector: F22

  • F33::Vector: F33

  • F34::Vector: F34 = −F43

  • F44::Vector: F44

  • normalization::Any: (1/2)∫F11 dμ of the table as given, before normalization

  • slopes::NTuple{6, Vector{FT}} where FT: Monotone-cubic slopes of log F11 and of F12/F11, …, F44/F11 at the nodes

  • source::String: Provenance: citation, table, and any transformation applied

Construction

TabulatedMuellerPhase(θ_deg; F11, F12, F33, F34, F22 = F11, F44 = F33,
                      normalization_tolerance = 1e-3, normalize = false,
                      source = "")

θ_deg is strictly increasing from 0 to 180. Elements are passed by name so they cannot be swapped by position; F22 = F11 and F44 = F33 hold for spheres. All elements use the standard convention above (F12 < 0 for Rayleigh scattering) and the normalization (1/2)∫F11 dμ = 1, i.e. (1/4π)∫F11 dΩ = 1. Tables of F/(4π) normalized as ∫ F/(4π) dΩ = 1 (e.g. Chowdhary et al. 2020, Table S1) must be multiplied by 4π first.

The integral (1/2)∫F11 dμ of the interpolated table is stored as normalization. The table is divided by it so that β₀ = 1; this is allowed only when |normalization − 1| ≤ normalization_tolerance, which covers rounding of published values, or with normalize = true.

Every element must satisfy |Fij| ≤ F11 (a necessary condition for a physical scattering matrix), within 1e-6 relative.

Example

# Rayleigh scattering (no depolarization), standard convention
θ  = 0.0:1.0:180.0
μ  = cosd.(θ)
pf = TabulatedMuellerPhase(θ; F11 = 0.75 .* (1 .+ μ .^ 2), F12 = -0.75 .* (1 .- μ .^ 2),
                           F33 = 1.5 .* μ, F34 = zero(μ))
greek_expansion(pf, 4; polarized = true).γ[3]   # ≈ √(3/2), as get_greek_rayleigh(0)

One phase function per tabulated wavelength.

Construction

λ [nm] strictly increasing, phases wavelength-independent phase functions of one float type. OceanOptics.GreekCoefficients — Type
struct GreekCoefficients{FT<:Real}

Expansion coefficients of one phase function or phase matrix, indexed [ℓ + 1] for ℓ = 0, 1, …, ℓ_max.

Fields

  • α::Vector{FT} where FT<:Real: α_ℓ: B[2,2] (empty when scalar)

  • β::Vector{FT} where FT<:Real: β_ℓ: B[1,1], the phase-function expansion

  • γ::Vector{FT} where FT<:Real: γ_ℓ: B[1,2] = B[2,1] (empty when scalar)

  • δ::Vector{FT} where FT<:Real: δ_ℓ: B[4,4] (empty when scalar)

  • ϵ::Vector{FT} where FT<:Real: ϵ_ℓ: B[3,4] = −B[4,3] (empty when scalar)

  • ζ::Vector{FT} where FT<:Real: ζ_ℓ: B[3,3] (empty when scalar)

Convention

p(μ) = Σ_ℓ β_ℓ P_ℓ(μ) with the (2ℓ+1) factor included, so β₀ = 1. The phase-matrix layout and signs are those of vSmartMOM's GreekCoefs (Sanghavi 2014 Eq. 16, Hovenier sign of γ and ϵ: γ₂ = +√(3/2) for Rayleigh scattering). evaluate_scattering_matrix converts back to the standard angular scattering matrix.

A scalar expansion has empty α, γ, δ, ϵ, ζ; a polarized one has all six of equal length.

Construction

GreekCoefficients(β; α, γ, δ, ϵ, ζ)

Pass none of α, γ, δ, ϵ, ζ (scalar) or all five (polarized). The constructor checks finiteness, β₀ = 1 within √eps, |β_ℓ| ≤ 2ℓ+1 (true for every non-negative phase function), and that α, γ, ϵ, ζ vanish for ℓ < 2, where their generalized spherical functions are identically zero. These are necessary conditions, not a proof of a correct import: compare asymmetry_parameter with published values as well.

OceanOptics.depolarized — Function
depolarized(g::GreekCoefficients) -> GreekCoefficients

The completely depolarizing phase matrix with phase function β: α = γ = δ = ϵ = ζ = 0, i.e. diag(p(Θ), 0, 0, 0). Scattered light is unpolarized and its intensity does not depend on the incident polarization. An explicit modelling approximation for scatterers whose phase matrix is unknown.

OceanOptics.evaluate_scattering_matrix — Function
evaluate_scattering_matrix(g::GreekCoefficients, μ) -> NamedTuple

Angular scattering matrix reconstructed from the expansion at scattering cosines μ, in the standard convention (Hansen & Travis 1974; Mishchenko et al. 2002: F₁₂ < 0 for Rayleigh scattering at 90°):

F = [F11 F12  0    0
     F12 F22  0    0
     0   0    F33  F34
     0   0   -F34  F44]

normalized so that (1/2)∫ F11 dμ = 1. Returns (; F11) for a scalar expansion and (; F11, F12, F22, F33, F34, F44) otherwise.

Shared interface

OceanOptics.AbstractOceanPhaseFunction — Type
abstract type AbstractOceanPhaseFunction{FT<:AbstractFloat}

Abstract base type for scattering phase functions and phase matrices.

A phase function p(μ), with μ the cosine of the scattering angle, is normalized as (1/2) ∫₋₁¹ p(μ) dμ = 1. Expansions follow p(μ) = Σ_ℓ β_ℓ P_ℓ(μ) with β₀ = 1; phase matrices use the layout and signs of GreekCoefficients.

Interface

  • phase_function_value(pf, μ) — p(μ).
  • phase_function_moments(pf, ℓ_max) — β_ℓ, ℓ = 0:ℓ_max. The default integrates p numerically in the scattering angle until converged; closed forms override it.
  • greek_expansion(pf, ℓ_max; polarized = false) — the expansion as GreekCoefficients. polarized = true requires is_polarizable(pf): a scalar phase function does not determine a phase matrix.
  • backscatter_fraction(pf), asymmetry_parameter(pf).
  • is_wavelength_dependent(pf) — if true, every query takes a wavelength as an extra argument: phase_function_moments(pf, ℓ_max, λ), greek_expansion(pf, ℓ_max, λ; …), backscatter_fraction(pf, λ). Wavelength-independent phase functions accept and ignore it.

New phase functions implement phase_function_value (or override phase_function_moments); phase matrices also implement is_polarizable(pf) = true and _polarized_greek(pf, ℓ_max).

OceanOptics.phase_function_moments — Function
phase_function_moments(pf, ℓ_max[, λ]) -> Vector{FT}

Legendre expansion coefficients β_ℓ, ℓ = 0:ℓ_max (index 1 is ℓ = 0), with p(μ) = Σ_ℓ β_ℓ P_ℓ(μ) and β₀ = 1.

The default evaluates β_ℓ = (2ℓ+1)/2 ∫₀^π p(θ) P_ℓ(cos θ) sin θ dθ by composite Gauss–Legendre quadrature in θ, graded geometrically toward the forward direction (with the analytic power-law tail below 1e-100 rad where the phase function declares one), refining until β_ℓ/(2ℓ+1) changes by less than 1e-10. It throws if the integral does not converge or if β₀ differs from 1 by more than max(1e-8, 8 eps(FT)) (the phase function is not normalized); it never renormalizes silently.

OceanOptics.backscatter_fraction — Function
backscatter_fraction(g::GreekCoefficients) -> FT

Backscatter fraction B = (1/2)∫₋₁⁰ p(μ) dμ of the finite expansion, evaluated exactly term by term. For a truncated expansion of a strongly peaked phase function this differs from the backscatter fraction of the phase function itself.

source

Backscatter fraction B = b_b / b; zero when b = 0.

source
backscatter_fraction(o::OceanLayerOptics) -> Vector

Scattering-weighted backscatter fraction of the components' phase functions per wavelength; zero where the layer does not scatter.

source
backscatter_fraction(pf[, λ]) -> FT

Fraction of scattering into the back hemisphere, B = (1/2)∫₋₁⁰ p(μ) dμ. The default integrates p numerically; closed forms override it.

source
backscatter_fraction(pf::FournierForandPhase) -> FT

Closed form (Fournier & Jonasz 1999; Mobley et al. 2002 Eq. 10): B = 1 − [1 − δ₉₀^(ν+1) − ½(1 − δ₉₀^ν)] / [(1 − δ₉₀) δ₉₀^ν].

source
backscatter_fraction(pf::HenyeyGreensteinPhase) -> FT

Closed form derived from direct integration of (1/2) ∫₋₁⁰ p(μ) dμ with substitution u = 1 + g² - 2gμ:

B(g) = (1-g²)/(2g) · [ 1/√(1+g²) - 1/(1+g) ]

At g = 0 the expression is 0/0; we short-circuit to B = 1/2 (isotropic).
