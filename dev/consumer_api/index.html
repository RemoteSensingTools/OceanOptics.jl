Consumer API

OceanOptics.jl publishes an RT-agnostic interface. Downstream solvers (vSmartMOM, HydroLight-style ODE codes, Monte-Carlo, SOS, …) consume it without OceanOptics having any knowledge of the solver. Project.toml therefore lists no RT-solver package under [deps] or [weakdeps]; adapters live on the solver side.

This page is the consumer contract: what the numbers mean, in which units and conventions, and which inputs are rejected rather than approximated.

Consumers working in wavenumber (vSmartMOM's core RT uses cm⁻¹) must apply the spectral-density Jacobian to per-nm quantities, and permute every per-wavelength array identically when reversing the order.

Phase-function convention

  • Normalization: (1/2) ∫₋₁¹ p(μ) dμ = 1, i.e. ∫ p dΩ / (4π) = 1.

  • Expansion: p(μ) = Σ_ℓ β_ℓ P_ℓ(μ) with β_ℓ = (2ℓ+1)/2 ∫₋₁¹ p(μ) P_ℓ(μ) dμ. The (2ℓ+1) factor is already included — adapters must not apply it again. Hence β₀ = 1, and |β_ℓ| ≤ 2ℓ+1 for every non-negative phase function; both are checked by the OceanLayerOptics constructor. The bound catches a doubled (2ℓ+1) factor only for strongly peaked phase functions and never a missing one (e.g. DISORT-style g^ℓ moments), so compare β₁/3 with the published asymmetry parameter when importing data.

  • Phase matrix: the Greek coefficients define, per order ℓ,

    B_ℓ = [β  γ   0   0
       γ  α   0   0
       0  0   ζ   ϵ
       0  0  -ϵ   δ]

    (Sanghavi 2014 Eq. 16; de Haan et al. 1987), with the Hovenier sign of γ used by vSmartMOM: γ₂ = +√(3/2)·dpl_p > 0 for Rayleigh scattering. Tables in other conventions (e.g. VLIDORT/Mishchenko-format expansion coefficients) differ at least in the sign of γ; convert them before use — vSmartMOM's docs/src/pages/conventions.md documents the known flips. The coefficients describe scattering relative to the scattering plane; rotation into the meridian-plane Stokes basis is the solver's job. α, γ, ϵ, ζ vanish at ℓ < 2, where their generalized spherical functions are identically zero; the constructors check this.

  • Truncation: layer_optics returns the first ℓ_max + 1 coefficients with no δ-M or other truncation correction; the solver applies its own. Numerically integrated moments (Fournier-Forand, Petzold) are rescaled so that β₀ = 1; this fixes the normalization but does not by itself establish the accuracy of the higher moments of strongly forward-peaked functions.

Polarization capability

Phase functionis_polarizablePolarized coefficients
RayleighWaterPhaseyesClosed form (Hansen & Travis 1974)
TabulatedGreekPhaseif all six are givenAs tabulated
FournierForandPhase, HenyeyGreensteinPhase, PetzoldPhasenonone — scalar only

A scalar β_ℓ sequence does not determine the other five coefficients, so OceanOptics never invents them:

  • phase_matrix_moments throws for scalar-only phase functions.
  • layer_optics(...; polarized = true) throws if any scatterer in the layer is scalar-only, unless the caller passes scalar_phase_approximation = :depolarizing. That option selects the completely depolarizing matrix diag(p, 0, 0, 0) for those scatterers (see depolarizing_phase_matrix_moments): a modelling choice, not real particle polarization.
  • Every OceanLayerOptics is either scalar (α, γ, δ, ϵ, ζ all empty) or polarized (all five present); is_polarized tells which.

Zero scattering

At a wavelength where a layer does not scatter, ϖ = 0, B = 0, β = [1, 0, 0, …] and all polarized coefficients are zero. A layer without any absorption or scattering has τ = 0.

Tabulated inputs

Benchmarks prescribe optical properties directly. Three types carry such values through the ordinary constituent and phase-function interfaces, without any of the package's empirical bio-optical defaults:

  • TabulatedAbsorber(λ, a; total = false, source = "")
  • TabulatedScatterer(λ, b, phase; source = "") — non-absorbing; b_b is derived from the phase function, so the two cannot disagree.
  • TabulatedGreekPhase(β; α, γ, δ, ϵ, ζ, source, normalize) or TabulatedGreekPhase(λ, β; …) for a wavelength-dependent table.

Values are defined only at their tabulated wavelengths; any other wavelength throws instead of interpolating. Each object records its source.

Total versus constituent absorption. Published absorption is often the bulk value of the whole water body, already containing water and CDOM — e.g. a_blk = a_p + a_y + a_w in Chowdhary et al. (2020) Eq. (11b). Mark such data with total = true; layer_optics then rejects any other absorbing constituent in the same layer, so water or CDOM cannot be counted twice.

# Chowdhary et al. (2020) AOS-II/III ocean body, Table 2
λ     = [350.0, 450.0, 550.0, 650.0]
a_blk = TabulatedAbsorber(λ, [0.0204, 0.0092, 0.0565, 0.3400]; total = true,
                          source = "Chowdhary et al. 2020, Table 2")
water = TabulatedScatterer(λ, [0.0134, 0.0045, 0.0019, 0.0010],
                           RayleighWaterPhase(depolarization = 0.0);
                           source = "Chowdhary et al. 2020, Table 2")
body  = OceanLayer(0.0, 100.0, AbstractOceanConstituent{Float64}[a_blk, water])
opt   = layer_optics(body, λ; ℓ_max = 16, polarized = true)
opt.ϖ    # ≈ [0.39644970, 0.32846715, 0.03253425, 0.002932551] (Table 2)

Not yet supported: angular scattering-matrix tables such as F₁₁(Θ), F₁₂(Θ), F₃₃(Θ), F₃₄(Θ), which need a reviewed generalized-spherical-function expansion before they can become Greek coefficients, and automatic conversion between Greek-coefficient conventions.

Validity and provenance

Each empirical model documents its source and intended range on the Materials page; bundled tables in data/ carry provenance headers. Interpolated tables are clamped to their end values outside the tabulated range (linterp), so a query beyond a model's validity range returns an edge value rather than an error — check the documented range before using a model there. The MasonConeFry2016 absorption table is not bundled yet; its first absorption query throws.

The stable contract

A downstream solver should consume only the symbols below. Anything else in the package is internal and can change in any minor version.

  • Output bundle: OceanLayerOptics, layer_optics, is_polarized, n_moments, n_wavelengths.
  • Constituent hierarchy: AbstractOceanConstituent, AbstractAbsorber, AbstractScatterer, AbstractAbsorbingScatterer, and the trait functions absorption, scattering, backscattering, attenuation, phase_function, is_total_absorption.
  • Phase functions: AbstractOceanPhaseFunction, phase_function_moments, phase_matrix_moments, is_polarizable, is_wavelength_dependent.
  • Tabulated inputs: TabulatedAbsorber, TabulatedScatterer, TabulatedGreekPhase.
  • Inelastic-process hierarchy: AbstractOceanInelasticProcess and trait functions excitation_absorption, emission, excitation_range, is_isotropic, inelastic_coefficient. Canonical docstrings in Inelastic processes.
  • Layer / column: OceanLayer and OceanColumn.

The two-pass solve convention (Fell 1997 §2.2.9)

Inelastic sources require two passes:

  1. Pass 1 — solve the elastic RT problem using OceanLayerOptics to get the internal radiance field at the excitation wavelengths λ'.

  2. Pass 2 — for each inelastic process p in layer.fluorophores, evaluate the source kernel

    \[J^I(\tau, \lambda) = \int_{\lambda'} b^I(\lambda', \lambda) \, \langle L(\tau, \lambda') \rangle_\Omega \, p^I(\cos\theta; \lambda', \lambda) \, d\lambda'\]

    with b^I(λ', λ) = excitation_absorption(p, λ') × emission(p, λ', λ). For isotropic processes (is_isotropic(p) == true) the angular factor p^I reduces to a scalar and the source contributes only to the m = 0 Fourier mode; for isotropic emission the excitation enters through the scalar irradiance (total intensity integrated over solid angle, direct and diffuse, up and down), not the downwelling plane irradiance. Anisotropic processes such as WaterRaman need the angular excitation field.

The adapter code that packs these kernels into a solver's internal format lives in the solver package.
